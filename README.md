# Lab 02 – Recombee: înregistrare proprietăți

## Dataset
- Domeniu: filme
- Sursă: [The Movies Dataset](https://www.kaggle.com/datasets/abdallahwagih/movies)
- Număr de intrări: 4000+
- Fișier: `movies.csv`

## Proprietăți înregistrate în Recombee
| Proprietate | Tip | Descriere |
|---|---|---|
| title | string | Titlul filmului |
| genres | string | Genurile filmului |
| vote_average | double | Nota medie |
| runtime | double | Durata în minute |
| homepage | string | Site-ul oficial |
| keywords | string | Cuvinte cheie |
| original_language | string | Limba originală |
| overview | string | Rezumat |
| popularity | double | Scor de popularitate |
| cast | string | Distribuția |
| director | string | Regizorul |
